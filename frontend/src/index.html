SciLog 기출문제 DB

과목별 기출 문제

  • 수학: 문제지 덤프
  • 화학: 문제지 덤프
  • 물리학: 문제지 덤프
  • 생명과학: 문제지 덤프
  • 컴퓨터공학: 문제지 덤프

'문제지' 링크를 클릭 시 과목별 역대 기출 문제 및 해설을 볼 수 있습니다. 컨트롤+P를 누른 후 "PDF로 저장" 을 선택해 pdf로 저장해서 인쇄하거나 노트 앱에서 사용하세요.

'덤프' 링크를 클릭 시 해설을 제외한 기출 문제가 JSON 형식으로 정리된 덤프 파일을 다운받을 수 있는 페이지로 이동합니다. 덤프가 생성되면 '다운로드' 버튼을 눌러 덤프 파일을 다운로드하세요. 덤프 파일은 LLM에 던져주고 비슷한 문제를 생성하도록 시키는 용도로 사용할 수 있습니다.

데이터베이스 파일

GitHub 릴리스 페이지 에서 문제, 해설 및 모든 이미지가 포함된 sqlite 데이터베이스 파일 (questions.db)를 다운받을 수 있습니다.
